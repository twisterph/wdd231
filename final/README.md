# CourtFinder

CourtFinder is a three-page responsive basketball court discovery website for the WDD231 individual website project.

## Pages
- index.html
- courts.html
- community.html
- form.html
- attributions.html

## Features
- Fetch API with local JSON data
- try...catch asynchronous error handling
- 16 dynamically generated court cards
- 4+ data properties per court
- Modal dialog for court details
- LocalStorage favorites
- DOM manipulation and event listeners
- Array methods
- Template literals
- ES Modules
- Responsive navigation
- Optimized WEBP images
